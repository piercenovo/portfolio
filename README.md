## 🚀 How To Use

###### To clone and run this application, you'll need [Git](https://git-scm.com) and [Node.js](https://nodejs.org/en/download/) (which comes with [pnpm](https://pnpm.io/) installed on your computer).

1. Fork this repository and clone the project

###### Please give me proper credit by linking back to [www.piercenovo.dev](https://www.piercenovo.dev/).

```bash
  git clone https://github.com/<YOUR USERNAME>/portfolio.git
```

2. Go to the project directory

```bash
  cd portfolio
```

3. Install dependencies

```bash
  pnpm install
```

4. Start the server

```bash
  pnpm dev
```

5. Build the static site (output in `out/`)

```bash
  pnpm build
```

- To add a **project**, add an entry to `src/content/projects.ts`; put the original image in `.images/` and run `pnpm images`

- To add a **technology**, add one line to `src/content/techs.ts`

- To change **experience, skills, profile or about**, edit the files in `src/content/`

- To change **UI texts**, edit `src/i18n/dictionaries/es.ts` and `src/i18n/dictionaries/en.ts`

- To change the **CV/Resume**, replace `public/pierce-novoa-cv-es.pdf` (ES) or `public/pierce-novoa-cv-en.pdf` (EN)

- To change the theme colors, edit the `@theme` block in `src/app/globals.css`
